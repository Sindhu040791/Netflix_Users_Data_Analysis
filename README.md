# 🎬 Netflix Users Data Analysis

## 📌 Project Overview
This project focuses on analysing Netflix user data to understand user demographics, subscription preferences, viewing habits and favourite genres.

## 🎯 Objectives
- 👥 Analyse user demographics such as age and country.
- 📊 Understand subscription type distribution.
- ⏱️ Explore user watch time.
- 🎭 Identify the most popular favourite genres.
- 📈 Create visualizations to understand user patterns.

## 🛠️ Tools & Technologies
- 🐼 Pandas
- 📊 Matplotlib
- 🗄️ PostgreSQL
- 💻 VS Code

## 📂 Dataset
The dataset contains **25,000 Netflix user records** with details such as:
- Age
- Country
- Favorite Genre
- Subscription Type
- Watch Time


## 📊 Key Analysis
- 🌍 User distribution by country.
- 👥 Age group analysis.
- 💳 Subscription type comparison.
- ⏱️ Watch time analysis.
- 🎬 Favourite genre distribution.

## 📉 Visualizations
Created charts using Matplotlib to understand user demographics, subscription preferences and viewing patterns.

## 📝 Conclusion
This project helped explore Netflix user behaviour through data analysis and visualization, providing insights into user preferences and viewing patterns.
